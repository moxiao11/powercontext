## 修复

1. 远程 Embedding 故障、维度错误、非法批次明确失败，禁止静默混入哈希向量。
2. 保存研究进度时保留决策 / 失败原因到 Source、Memory 和 Handoff，记忆带会话标识。
3. 部分保存失败返回 `status=partial`、`failed_writes`，界面不再误报全部成功。
4. 只在条目内容版本未变化时重试修订，阻止陈旧客户端覆盖并发修订。
5. 恢复摘要优先采用有效记忆；Handoff 标为历史快照，避免纠正 / 停用的内容复活。
6. 修复 omissions 数组展示、切换项目时页面状态隔离，增加移动端导航。
7. 限制上传读取长度，避免先把超限文件全部读入内存。
8. Nginx 使用 Docker DNS 持续解析，修复后端容器重建后网页 502。
9. Docker 前端用 `npm ci` 和锁文件固定安装。
10. 排除宿主依赖和本地配置的 Docker 上下文；以实际运行包生成 Python 约束锁，重新构建并复测 148 项测试。
