## 三、核心产品功能

### 功能 1：智能论文知识库

实现完整的科研资料导入、管理和检索功能。

支持：

- 上传 PDF、Markdown、TXT 文档
- 自动提取正文和文档元数据
- PDF 文本按段落切分，并保留原始页码信息
- 将文档分块和索引存入 seekdb
- 支持关键词检索、向量检索及混合检索
- 按论文标题、研究主题和上传时间筛选
- 使用 LLM 根据检索证据回答科研问题
- 回答中显示论文名称、页码和引用段落
- 用户可以点击引用查看对应原始内容

示例：

用户上传三篇关于 Embodied Question Answering 的论文。

用户提问：

“这些论文分别使用了什么记忆架构？它们之间有什么不同？”

系统从 seekdb 检索相关论文段落，生成有来源依据的比较结论。

要求：

检索必须真实经过 seekdb，不得使用预先写死的搜索结果。

对于缺少足够证据的问题，明确说明无法确认，不得捏造论文内容。

### 功能 2：科研实验追踪

用户可以记录每一次科研实验。

每条实验包含：

- 实验名称和所属研究项目
- 实验目标与假设
- 使用的方法
- 模型、参数及配置
- 数据集名称
- 实验结果和评价指标
- 遇到的问题
- 失败原因分析
- 下一步改进方向
- 创建时间与更新时间

支持 Markdown 实验日志和 JSON 指标导入。

系统可以检索历史实验，并回答：

“之前为什么放弃这个方案？”

“哪些实验使用了相同的数据集？”

“目前效果最好的实验是哪一次？”

“最近三次实验分别改进了什么？”

实验数据使用 seekdb 保存和查询，重要结论、决策及后续计划写入 PowerContext。

### 功能 3：科研长期记忆引擎（核心创新）

这是项目最重要的功能。

使用 PowerContext 实现跨会话科研记忆。

需要管理以下记忆：

1. Research Profile：用户的研究方向与长期目标
2. Project Context：当前项目背景与研究任务
3. Decisions：研究过程中做出的重要决策及原因
4. Failures：失败尝试及失败原因
5. Progress：任务完成情况
6. Next Actions：后续研究计划

用户每次完成科研工作后，可以点击：

**保存本次研究进度**

系统自动总结当前科研会话，提取已完成事项、关键结论、未解决问题及后续步骤，写入 PowerContext。

当用户关闭会话并重新打开时，系统能够读取此前的研究上下文。

例如：

第一天：

“我准备采用 YOLO-World + SAM 进行实例检测，先测试无记忆 baseline。”

第二天开启新的科研会话：

“继续昨天的工作。”

系统应能够恢复真实保存的研究上下文，回答：

“昨天确定了检测方案，目前准备验证无记忆 baseline，下一步是实现实验评估。”

要求：

- 使用 PowerContext 实际持久化并读取记忆
- 不允许只依靠浏览器 localStorage 模拟跨会话记忆
- 实现研究记忆的查询、更新和删除
- 支持多个独立研究项目
- 不同项目的记忆相互隔离
- 提供查看记忆来源的功能
- 支持用户纠正错误或过期的记忆
- 避免把模型猜测当作已经确认的研究事实

优先使用 PowerContext 官方支持的 Memory、Handoff 等能力，实际接口和数据结构以当前仓库及官方 SDK 文档为准。

### 功能 4：AI 科研助手

实现具备科研上下文的 AI 对话页面。

助手回答问题时，应根据问题类型选择数据来源。

**论文问题：** 检索 seekdb 中的论文证据。

**实验问题：** 查询 seekdb 中的实验记录。

**研究进展问题：** 读取 PowerContext 中的科研记忆。

**复杂综合问题：** 将两种数据结合形成回答。

回答需要尽量包含：

- 直接结论
- 依据与引用
- 相关历史研究决策
- 建议的下一步工作

需要提供“当前回答使用了哪些数据”的可解释性面板。

例如：

知识来源：Sequential-EQA.pdf，第 6 页

历史记忆：2026-10-25 保存的研究决策

实验记录：Experiment #12

对无法核实的信息，必须明确告知用户。

### 功能 5：自动科研周报

系统能够根据指定日期范围，自动汇总：

- 本周阅读的论文
- 重点研究结论
- 完成的实验
- 实验结果与变化
- 遇到的问题
- 已经做出的技术决策
- 尚未完成的任务
- 下周研究计划

生成结构清晰的 Markdown 周报。

支持预览、编辑、复制与下载。

周报中的实验指标及已完成事项必须基于实际记录，不得虚构。

### 功能 6：科研知识关联图（增强功能）

在核心功能完成并通过验收后实现。

可使用 React Flow 或其他成熟的可视化库。

展示论文、研究项目、实验和研究决策之间的关系。

例如：

Sequential-EQA → 记忆机制 → 我的 3D-MEM 项目 → Experiment #12 → 失败结论 → 新实验计划

点击节点可以查看对应证据或历史记录。

该功能不应影响核心功能的开发与交付。
