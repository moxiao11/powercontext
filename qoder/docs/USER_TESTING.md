## 1. 测试目标

验证六项功能在真实使用场景下是否可用，重点确认三条硬性要求：

1. 检索**真实经过 seekdb**，不是预先写死的结果
2. 跨会话记忆**真实来自 PowerContext**，不是浏览器 localStorage
3. 周报中的实验指标与已完成事项**基于实际记录**，不是虚构

以及一条体验要求：没有配置大模型 API Key 时，
资料导入、数据库检索、实验记录等非生成式基础功能**仍然可用**。

## 6. 如何参与测试

如果你愿意帮忙测试，请按下面的流程，并把结果填回 §3 / §4：

1. 按 [SETUP.md](SETUP.md) 部署（推荐路径 A：Docker Compose）
2. 跑一遍 `python scripts/e2e_demo.py --api http://127.0.0.1:8100 --keep`
   确认环境正常（应输出 `PASS 全部检查通过`）
3. 在 UI 里创建一个**自己的**项目（不要动演示项目），按 §2 的用例逐条走
4. 记录：用例编号、实际结果、通过/失败、遇到的问题
5. 特别注意 §2.4 的 MEM-03 / MEM-04 —— 这是本项目的核心创新，
   请务必用**无痕窗口或清空站点数据**的方式验证跨会话恢复
6. 把 §3 与 §4 的表格填好后提交（或反馈给开发者）

> 请勿在公开演示环境上传未发表的研究资料：当前后端 `/api/*` **没有鉴权**，
> 任何能访问端口的人都能读写全部项目数据。见 [DEPLOYMENT.md §5](DEPLOYMENT.md)。
