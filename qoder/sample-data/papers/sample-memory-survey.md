# 具身智能体记忆机制综述（示例）

> **示例数据（SAMPLE）** — LabTrace 比赛演示用原创文档，内容与方法分类均为虚构示例，
> **不代表任何真实论文或真实科研结果**。

## 摘要

本文梳理具身智能体（Embodied Agent）中常见的记忆机制，按表示形式分为四类：
稠密特征记忆、符号语义记忆、空间栅格记忆与结构化图记忆，
并讨论它们在长时序问答（EQA）与导航任务中的适用性、内存开销与失效模式。

## 1. 为什么具身任务需要记忆

具身任务与静态问答的根本差异在于**信息随时间到达且不可重复获取**：
智能体在 t 时刻看到的物体，在 t+k 时刻可能已不在视野内。
若系统不保留历史观察，则任何依赖此前信息的问题都无法回答。
因此记忆机制的设计目标是：在有限算力与内存下，保留对后续决策有用的信息。

## 2. 四类记忆机制

### 2.1 稠密特征记忆（Dense Feature Memory）

将每帧编码为特征图并缓存最近若干帧。优点是无需额外检测器、保留完整外观信息；
缺点是内存随帧数线性增长，且检索需要在全帧上做注意力计算，长序列下代价高。
典型配置为缓存 32–128 帧。

### 2.2 符号语义记忆（Symbolic Semantic Memory）

将观察抽象为离散条目，如 `(object, position, room)` 三元组或自然语言描述。
优点是内存占用小、可解释、便于精确检索与计数；
缺点是丢弃外观细节，依赖检测器的准确性，检测失败即记忆缺失。
Sequential-EQA 的分层场景记忆（HSM）属于此类。

### 2.3 空间栅格记忆（Spatial Grid Memory）

以二维占据栅格或三维体素维护空间结构。优点是直接支持路径规划与可通行性判断；
缺点是对物体级语义支持弱，且内存随探索面积增长。3D-MEM 属于此类。

### 2.4 结构化图记忆（Structured Graph Memory）

将房间、物体、关系表示为图节点与边，支持多跳关系推理（如"厨房左边的房间里有什么"）。
优点是关系表达能力强；缺点是图构建依赖可靠的空间感知，构建错误会级联影响推理。

## 3. 任务与记忆的匹配关系

| 任务类型 | 推荐记忆 | 理由 |
| --- | --- | --- |
| 长时序 EQA（问物体位置/计数） | 符号语义记忆 | 精确检索、可计数、内存可控 |
| 连续导航 | 空间栅格 / 体素记忆 | 需要可通行性的稠密空间结构 |
| 多跳关系问答 | 结构化图记忆 | 需要沿关系边推理 |
| 需要外观细节的问答 | 稠密特征记忆 | 符号摘要已丢弃外观 |

## 4. 常见失效模式

1. **记忆写入错误**：检测或位姿误差把错误内容写入记忆，后续检索必然出错，且难以自我纠正。
2. **记忆膨胀**：长序列下条目无限增长，检索延迟与内存上升，需要遗忘或合并策略。
3. **记忆与当前观察冲突**：物体被移动后记忆未更新，智能体依据过期记忆行动。
4. **错误合并**：同类物体在不同位置被合并为同一条目，导致计数类问题系统性错误。

## 5. 评测建议

评测记忆机制时，除了任务成功率，还应报告：
内存峰值与序列长度的关系、检索延迟、以及**记忆依赖型问题**的子集准确率
（即必须使用历史信息才能回答的问题），否则提升可能来自感知而非记忆。

## 6. 开放问题

- 如何在符号记忆与稠密记忆之间做自适应切换；
- 如何设计可验证的遗忘策略，避免过期记忆污染决策；
- 如何让智能体在回答时明确说明"记忆中没有相关信息"，而不是编造答案。
