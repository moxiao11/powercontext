01把一次研究，变成可以继续的积累

01 / 找到证据

导入 PDF、Markdown 与 TXT，在 seekdb 中建立分块、全文及向量索引。每条检索结果保留标题、页码和原文。

  • 关键词 / 向量 / 混合检索
  • RRF 融合与来源说明
  • PDF 精确页码引用

02 / 记住实验

记录假设、参数、数据集、指标和失败原因。直接对比数据库中的实验，追问“为什么放弃这个方案”。

  • JSON 实验导入
  • 指标差值与最优实验
  • 结论关联长期记忆

03 / 接续研究

把完成事项、决策和下一步保存到 PowerContext。新会话读取有效记忆和 Handoff 历史，恢复真实进度。

  • 按项目独立 Scope
  • 记忆修订 / 停用
  • 研究周报预览和导出

04每一步，都可以自己验证

A / 论文证据检索

原创资料入库 → 三模式检索 → 原文引用。两页 PDF 的 ROOMMERGE2026 引用精确落在第 2 页。

B / 实验对比

导入四条示例实验，accuracy 从 41.2 到 58.7，差值 17.5。数字从数据库读取，标注为示例。

C / 跨会话恢复

保存进度并提交 Handoff，独立 HTTP 客户端恢复。修订计划后读到新版本，拒绝陈旧客户端覆盖。容器重启后条目 ID 与交接版本保持一致。

05在自己的环境中跑起来

Docker Desktop / Compose，建议至少 6 GB 可用内存。所有密钥保留在本地环境文件。

Windows / PowerShell

cd qoder
.\scripts\start.ps1
# 默认网页：http://127.0.0.1:5173

Linux / macOS / WSL

cd qoder
cp .env.example .env
# 在 .env 中填写随机 POWERCONTEXT_AUTH_TOKEN
docker compose up -d --build

独立 seekdb、可选模型和完整配置见 运行说明。当前为本地单用户工作台，尚无生产级多用户鉴权；公开在线实例需另行部署和配置访问控制。
